# CSBUWQ

My attempt at making a (working) CS:GO mod with all of the old features re-implemented to be able to run locally.

> [!WARNING]
> This project is incredibly incomplete, and is not even remotely ready for use.

# Build

1. Clone the repo
2. Run `Setup.bat`
3. Run `Build.bat`
4. All relevant output files will be found in `Out/`
